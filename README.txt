KCHZ Maze — Android project

This project wraps the supplied index.html game in a fullscreen Android WebView.

Build APK:
1. Install Android Studio.
2. Open this folder (KCHZ-Maze-Android) in Android Studio.
3. Allow Gradle sync and install Android SDK Platform 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The APK will be in app/build/outputs/apk/debug/app-debug.apk.

Application ID: com.kchz.maze
Minimum Android: 6.0 (API 23)
