СБОРКА APK БЕЗ КОМПЬЮТЕРА

1. На планшете открой https://github.com и войди или создай аккаунт.
2. Создай новый репозиторий (New repository), назови его KCHZ-Maze-Android. Можно выбрать Public или Private.
3. Распакуй этот ZIP на планшете.
4. В репозитории нажми Add file -> Upload files и загрузи ВСЕ файлы и папки из распакованной папки KCHZ-Maze-Android. Важно сохранить папку .github/workflows/android.yml; если файловый менеджер скрывает папки с точкой, создай workflow через Add file -> Create new file с именем .github/workflows/android.yml и вставь содержимое android.yml.
5. Нажми Commit changes.
6. Открой вкладку Actions. Дождись завершения Build KCHZ Maze APK (зелёная галочка).
7. Открой завершённый запуск workflow, найди Artifacts и скачай KCHZ-Maze-debug-apk.zip.
8. Распакуй скачанный архив — внутри будет app-debug.apk. Нажми на него, чтобы установить.

Не отправляй никому пароль от GitHub. Для установки APK может понадобиться разрешить установку приложений из выбранного браузера или файлового менеджера.
